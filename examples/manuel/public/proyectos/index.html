Carburo — Gestión Inteligente de Combustible

Trabajo de Fin de Grado (TFG) & Ecosistema Móvil y Web

Descripción

Carburo es una plataforma integral orientada a optimizar el gasto de combustible de los usuarios, proporcionando información en tiempo real sobre estaciones de servicio, fluctuación de precios y registro detallado de consumos y repostajes.

El ecosistema se apoya sobre una arquitectura modular basada en servicios REST desacoplados:

  • Android SDK
  • Java
  • Spring Boot
  • PostgreSQL
  • REST API
  • Docker
  • Git / GitHub
  • Visitar sitio web oficial (carburo.app) →
  • Repositorio en GitHub (github.com/manugbd) →

Componentes del ecosistema Carburo

Aplicación Móvil Nativa (TFG Principal)

Constituye el núcleo del Trabajo de Fin de Grado en Ingeniería Informática del Software. Desarrollada de forma nativa para la plataforma Android, implementa geolocalización, filtrado por tipo de carburante, comparativa visual de precios y registro analítico de eficiencia de combustible de los vehículos registrados.

Plataforma Web y Servicios Complementarios

Desarrollo complementario que expande el ecosistema hacia la web, permitiendo a los usuarios consultar resúmenes estadísticos, mapas interactivos de gasolineras y gestionar perfiles desde cualquier navegador.

Infraestructura Web Segura y Automatizada

Proyecto de Máster Universitario en Ingeniería Web

Descripción

Desarrollo de un entorno integral de infraestructura como código (IaC) para el despliegue orquestado y seguro de aplicaciones web en entornos virtualizados y cloud. El sistema implementa aprovisionamiento automatizado, configuración de redes aisladas, cortafuegos perimetrales, contenedores y gestión de certificados criptográficos HTTPS.

  • OpenStack
  • Terraform
  • Ansible
  • Linux (Debian/Ubuntu)
  • Docker & Compose
  • Seguridad & HTTPS

Sitio Web Personal y Académico (ECW)

Estándares y Computación Web

Descripción

El presente sitio web, concebido bajo los más rigurosos principios de la asignatura Estándares y Computación Web. Desarrollado mediante el generador estático Eleventy y plantillas Nunjucks, garantiza una separación estricta de responsabilidades, HTML5 semántico puro sin utilización de elementos div genéricos, CSS externo con gestión de cascada y total validación según las pautas del consorcio W3C.

  • HTML5 Semántico
  • CSS3 / Cascada
  • Eleventy (11ty)
  • Nunjucks
  • Accesibilidad WCAG
  • Validación W3C
