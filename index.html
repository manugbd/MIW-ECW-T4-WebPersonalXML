Tu web empieza en un XML

PersonalWebML transforma tus datos en cinco páginas listas para usar.

1. Prepara tus datos

Descarga el esquema y un ejemplo. Edita la identidad, el contacto y las secciones: puedes repetir artículos, párrafos, listas y enlaces.

Descargar XML Schema (.xsd)

  • XML de Manuel — Ver ejemplo
  • XML de Ana — Ver ejemplo
  • XML de Carlos — Ver ejemplo

2. Genera y descarga

Máximo 2 MB. El archivo se procesa en tu navegador. Abre esta aplicación con Live Server o cualquier servidor estático.

Selecciona un XML para comenzar.

3. Completa las imágenes

El ZIP incluye las cinco páginas HTML, todos los CSS y JS originales, el favicon y la carpeta img/ vacía. Copia ahí las imágenes con los nombres escritos en tu XML.

Extrae el ZIP y abre public/index.html. También puedes publicar la carpeta public en un servidor estático.
